## **Выполненная работа:**

### **Оценки студента**

Был реализован новый экран оценок студента. Он использует ручку:

```jsx
GET /api/student/grades/all
```

На странице отображаются:

- общий процент успеваемости;
- количество предметов;
- текущие баллы;
- количество оцененных работ;
- список предметов;
- таблица контрольных точек;
- фильтр по предмету.

Экран был оформлен в стиле нового личного кабинета: добавлены summary-блоки, карточки предметов, таблица работ и адаптивная верстка.

### **Посещаемость студента**

Был добавлен экран посещаемости студента. На нём отображаются:

- количество отметок за год;
- количество активных дней;
- лучший день по количеству отметок;
- календарь посещаемости;
- история отметок за выбранный месяц.

Текущая backend-ручка возвращает данные по дням, поэтому на фронте сейчас отображается количество отметок за дату. Более детальные статусы, например `опоздал`, `отсутствовал` или `не отметился`, потребуют доработки backend API.

### **Общий Dashboard**

Была добавлена общая главная страница `DashboardPage`  для разных ролей.

Для студента dashboard содержит быстрые переходы:

- расписание;
- оценки;
- посещаемость;
- аналитика.

Для преподавателя добавлены переходы к рабочим разделам:

- создание QR для посещаемости;
- оценки;
- статистика группы;
- профиль.

Для ролей `admin`, `head`, `dean`  dashboard показывает краткую сводку по данным, доступным пользователю.

### **2FA при входе**

Была восстановлена поддержка двухфакторной авторизации. Если backend возвращает ошибку `requires_2fa`, форма входа показывает поле для ввода кода 2FA.

### Merge

Слил ветку fix_frontend в main, заодно устранив пару конфликтов и удалив старую ветку.
