# **Отчет по фронтенду 14.08**

## **Цель недели**

Реализовать полноценный раздел административной панели для управления пользователями системы

## Работа:

В административную панель был добавлен отдельный раздел для просмотра и управления учетными записями пользователей.

На странице реализованы:

- общий список пользователей;
- отображение логина, email, роли, статуса аккаунта и состояния 2FA;
- поиск пользователя по логину или email;
- фильтрация по роли и статусу;
- постраничная навигация;
- краткая сводка по количеству пользователей.

### **Создание пользователя**

Добавлена форма создания новой учетной записи. Администратор может указать:

- логин и пароль;
- email;
- роль пользователя;
- ФИО;
- группу, кафедру или факультет в зависимости от выбранной роли;
- должность преподавателя.

Форма проверяет обязательные поля до отправки данных на backend.

### **Редактирование пользователя**

Для существующих учетных записей реализовано редактирование:

- логина;
- email;
- пароля;
- роли;
- статуса учетной записи;
- связанного профиля или области доступа при изменении роли.

Также добавлено архивирование пользователей. Собственную учетную запись администратор не может случайно архивировать или лишить административной роли через интерфейс.

### **Навигация и адаптивность**

Для роли администратора была подготовлена отдельная навигационная панель со ссылкой на раздел пользователей. Быстрый переход в него также добавлен на главную страницу администратора.

Интерфейс адаптирован для компьютеров, планшетов и телефонов. На небольшом экране таблица пользователей преобразуется в компактный список, а формы отображаются в одну колонку.

## **Проверка**

После реализации были успешно выполнены:

```jsx
npm run check-api
npm run build
```

Ошибок проверки API-контракта и production-сборки не обнаружено.
